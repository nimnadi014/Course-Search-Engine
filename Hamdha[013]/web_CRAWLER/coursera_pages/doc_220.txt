Am I missing out on life experiences by doing this online? Not at all! What programming languages will I learn in this degree programme? You will learn problem-solving concepts and sharpen programming logic via coding languages like C, Java, SQL, Python, HTML and CSS as part of this degree programme. Can I get accepted into master’s programmes from BITS Pilani with this degree?‎ Yes. This is a recognised degree programme from BITS Pilani. As long as you meet the eligibility requirements, you can apply to any programme offered by BITS Pilani. Is there an on-campus equivalent to this programme? BITS Pilani does not offer BSc Computer Science on campus. Can I switch between online and on-campus programmes? No. This is an exclusively online programme from BITS Pilani. Can I visit the BITS Pilani campus? This is a completely online degree programme, and all classes and exams will be conducted online.
